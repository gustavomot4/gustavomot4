### Sobre

- Na **Stefanini**, aplico LLMs e agentes de IA à modernização de sistemas legados em mainframe: escrevo os PRDs que guiam os agentes na conversão de COBOL, Natural e Adabas para tecnologias atuais.
- Por conta própria, construo a infraestrutura em volta dos modelos: orquestração entre vários LLMs, processos com portões de qualidade, avaliação estatística e deploy com volta automática quando algo falha.
- Só confio no que foi medido: cada projeto abaixo traz o número que prova que funciona e o código aberto para conferir.
